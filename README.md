# Maryam Rutqvist Ristimäki · Portfolio

My personal developer portfolio, built from scratch with HTML, CSS and vanilla JavaScript – no frameworks.

🔗 **Live:** [your-link-here]

## Features

- **About me** – who I am and what I work with
- **Projects** – clickable project cards linking to each GitHub repo
- **Contact form** – sends messages straight to my inbox
- **Language switch** – Swedish / English
- **Scroll animations** – sections and images fade into place as you scroll
- **Responsive** – works on mobile, tablet and desktop

## Built with

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- JavaScript (ES6+, Intersection Observer)
- [FormSubmit](https://formsubmit.co) for the contact form

## Run locally

1. Clone the repo
```bash
   git clone https://github.com/mristimaki/portfolio.git
```
2. Open the folder in VS Code
3. Start **Live Server** (right-click `index.html` → *Open with Live Server*)
